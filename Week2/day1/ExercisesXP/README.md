# Exercises XP — Week 2, Day 1

Les dix exercices, leurs réponses et leurs résultats se trouvent dans **[exercises_xp.ipynb](exercises_xp.ipynb)**.

## Ouvrir et exécuter facilement

[Ouvrir le notebook dans Google Colab](https://colab.research.google.com/github/cojoseph258/baba.py/blob/main/Week2/day1/ExercisesXP/exercises_xp.ipynb), puis choisir **Exécution → Tout exécuter**.

Dans VS Code ou Jupyter, ouvrir le notebook, choisir un noyau Python et cliquer **Run All / Tout exécuter**. La première cellule prépare les bibliothèques et les données. Une connexion Internet est nécessaire au premier lancement et pour l'import JSON de l'exercice 10.

L'aperçu GitHub permet de lire les réponses et les résultats déjà enregistrés ; il n'exécute pas Python. Le notebook fonctionne seul, sans `analysis_helpers.py`, `datasets.json` ni téléchargement manuel. Les exports sont créés dans le dossier `results/` de l'environnement d'exécution.

Les réponses rédigées aux exercices 1, 6 et 7 sont incluses dans le notebook et dans [reponses.md](reponses.md).
